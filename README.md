# MathTips 🧮

> Dicas e atalhos de matemática de forma simples e prática.

## 📖 Sobre o projeto

O **MathTips** é um projeto que reúne dicas de matemática para ajudar nos estudos e no cálculo do dia a dia. 

## ✨ Funcionalidades

- Cadastro Simples de Professor
- Listagem de dicas por categoria 
- Exemplos resolvidos passo a passo 
- Interface simples e responsiva 

## 🛠️ Tecnologias

- PHP, CSS e JavaScript
